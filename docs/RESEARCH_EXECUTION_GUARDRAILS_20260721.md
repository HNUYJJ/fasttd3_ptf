# 科研执行总准则：始终服务于 PTF × FastTD3 × HumanoidBench 主线

> 冻结日期：2026-07-21  
> 决策人：Human PI  
> 适用对象：ChatGPT/Codex、Claude、GLM 及后续参与本项目的代理  
> 优先级：本准则高于局部实验优化、工程审计偏好和代理自行提出的支线。

## 1. 不可偏离的科研北极星

本课题研究 **HumanoidBench 上基于 PTF 的迁移强化学习**。基座固定为 FastTD3，
目标是让冻结的跨任务 source policy 在 target student 的不同训练阶段被正确选择、
切换或拒绝，通过 reward-bearing bootstrap 与受控 replay 提高目标任务的样本效率或
性能上限，并最终得到不依赖 source 的 student。

总路线保持为：

> **迁移性评估 → 自动选择/终止教师 → reward-bearing bootstrap →
> admission-consistent replay → source-free student；MCG 为可选细粒度执行/蒸馏层。**

## 2. 后续只允许围绕三个核心科学问题推进

1. **教师价值信号**：当前阶段应选择哪个 source、何时终止、何时严格退化为
   100% student？
2. **行为/数据双通道迁移**：source 何时具有行为 authority，其经验何时具有 replay
   eligibility，二者如何联合控制？
3. **真实迁移收益**：方法能否在 hurdle、stair、truck 等困难任务上加速学习、提高
   上限，或解决 scratch/已有方法难以解决的问题？

不能推进以上任一问题的工作，不立项。

## 3. 每项工作启动前的强制立项门

开始阅读、写代码或跑实验前，必须用不超过五句话回答：

1. 它对应上述哪个核心问题？
2. 它检验的唯一主要假设是什么？
3. 结果为正或为负时，分别会改变哪个论文结论或下一步决策？
4. 是否已有实验回答过同一问题？若有，为什么不是重复？
5. 最小成本的可否证方案是什么？

任一问题答不清楚，停止该工作。不得以“更严谨”“更完整”“也许有用”为理由自动扩张。

## 4. 明确停止投入的事项

- 不再对 bounded lease 的 TTL、epsilon、小数阈值或同一矩阵做追调。
- 不再通过换阈值、换单个 task 或增加相似 probe 抢救 SIV/SHU/P0/adaptive 等已裁决失败线。
- 不再把 `T^0`、即时 source return 或 `T^critic` 符号重新包装成可靠迁移性指标。
- 不再围绕逐 bit 一致、无关边界条件或不会改变论文结论的审计细节反复复核。
- 不为了“代码更漂亮”改动已通过且不阻塞核心假设的基础设施。
- 不启动无法区分机制假设、只会增加曲线数量的大规模实验矩阵。
- 不把 exact abstention、provenance、replay lifecycle 或 MCG 的工程正确性包装成已经
  解决自动教师选择或稳定提高性能。

## 5. 已有机制的固定定位

- **Reward-bearing bootstrap**：当前已证的主要性能通道，继续作为主框架组成部分。
- **WFix/静态 RBO**：当前有效静态基线与保底方法，不冒充动态迁移性指标。
- **Exact abstention、quarantine、provenance、replay lifecycle**：必要且基本完成的
  基础设施；除非阻塞新核心机制，不再扩建。
- **Bounded bank lease**：已回答 replay 尾部 hard-exit 问题；工程成立、性能异质，关闭。
- **MCG**：可选身体模块级 authority/蒸馏层；当前不是主要性能增益来源。
- **SIV/SHU/P0/adaptive revocation**：保留为失败分析和测量边界，不调参复活。
- **Stage-conditioned transferability/teacher value**：尚未解决，是当前最重要的科学断点。

## 6. 最小充分验证标准

新机制默认只需要：

1. 既有负结果碰撞检查；
2. 聚焦单元测试；
3. 一次真实环境 smoke，确认数据流和学习信号；
4. 一个正迁移任务和一个负迁移/弃权任务的最小可行性实验；
5. 通过后再进行 3 seeds 正式实验与困难任务扩展；
6. 记录关键机制中介量和训练曲线。

除非某个额外审计会改变科学裁决，否则禁止增加多轮逐字段、逐 bit 或小数级复核。
工程验证的目的仅是保证实验可解释，不是替代机制创新。

## 7. 实验与停止规则

- 一个实验必须只有一个主要干预和一个预先写明的主要结论。
- 先小型 falsification gate，后正式训练；gate 失败即停止，不换阈值救结果。
- 正式实验优先使用能承载论文价值的任务；边界任务只在验证 exact abstention 或负迁移
  时使用，不长期纠缠。
- 正式结果若方向异质，先判断假设是否已经回答；不得默认增加 seeds、窗口或参数网格。
- 任何新方向最多经历一次设计复核和一次实现复核；除阻塞性错误外，不进入循环审查。
- 高成本实验仍需 PI 批准，但不得把 run card 写作本身变成主要工作量。

## 8. 论文价值优先级

工作优先级从高到低为：

1. 提出并验证可靠的阶段条件 teacher-value/transferability 机制；
2. 在困难 HumanoidBench 任务上形成明确的样本效率或性能上限收益；
3. 解释 source 如何通过状态覆盖和 replay/update 两条通道影响 student；
4. 完成必要消融和负迁移边界；
5. 工程审计与复现材料。

第 5 项只能服务于前四项，不能反客为主。

## 9. 代理每轮工作的自检句

每次准备继续推进前，必须在内部重新检查：

> **这项工作是否直接让“自动选教师/终止、双通道迁移或困难任务性能”前进一步？
> 如果不能，就停止，不用审查或实验数量制造进展感。**
