## 0. 执行摘要

### 0.1 最初的大方向没有改变

本课题从创立之初要研究的就是：

> 在 HumanoidBench 上，将已经训练并冻结的跨任务源策略作为可复用技能，通过
> PTF 风格的教师选择、终止与策略迁移机制，帮助 FastTD3 学生策略更快或更好地
> 学会目标任务。

最初设想的完整链条是：

```text
训练源策略
→ 冻结源策略库
→ 处理 source/target observation 与 action 语义适配
→ 衡量源策略对当前目标学生的可迁移性
→ 自动选择当前最合适的教师
→ 教师策略迁移 / 经验轨迹注入
→ warmup bootstrap
→ 学生 source-free 自主强化学习
→ 可选 MCG 模块化控制或蒸馏
→ source-free student 评估
```

课题中途虽然经历了多轮机制重构，但始终没有改变以下核心约束：

1. FastTD3 是固定 backbone，不改换其他主算法；
2. 创新点必须围绕 PTF 式跨任务策略迁移；
3. 重点不是单纯提高一条曲线，而是回答“哪个 source 何时值得介入，以及如何避免
   source 数据长期毒害学生”；
4. 最终评估对象必须是脱离 source 后独立执行的 student。

### 0.2 目前最扎实的正向结果

截至 2026-07-27，已经得到以下相对稳固的结论：

1. **冻结源策略确实可以产生有效迁移。**
   - 经典 PTF 的 fixed-walk 动作蒸馏在 Hurdle 上使 5k–95k AUC 相对 scratch
     3/3 seeds 提升，平均 `+100.993`；
   - Reward-bearing bootstrap 在 Hurdle、Truck、Cabinet、Powerlift 等任务上能够
     加速学习，有些任务在较长区间仍保持收益。

2. **RBO/bootstrap 是此前整套 SAFE/WFix/MCG 框架的主要性能通道。**
   `bootstrap_only ≈ full`、`no_bootstrap` 弱或为负；MCG gate 尚未证明具有独立的
   稳定性能贡献。

3. **源策略身份很重要。**
   4 个 terrain 任务 × 3 seeds 的 WFix 解耦实验中，加权选源相对 uniform source
   allocation 的平均 95k AUC 增益为 `+77.9`，12 个 task-seed cell 中 11 个为正，
   paired `t=3.08`。执行 horizon 的总体差异为 `−11.4`，`t=−0.46`，没有形成统一
   主效应。

4. **Hurdle 已建立稳定的 source-specific RBO 标签。**
   在相同 0.5 source / 0.5 student 剂量下：
   - `run − scratch`：5k–25k nAUC 平均 `+146.398`；
   - `walk − scratch`：平均 `+68.351`；
   - `run − walk`：平均 `+78.046`；
   - 三个 seed 的 AUC 与 30k source-free endpoint 均满足
     `run > walk > scratch`。

5. **Student-inclusive exact abstention 和 replay 生命周期控制已在工程上成立。**
   当没有 source 被接纳时，source behavior、source replay 与 source critic sampling
   可以严格为零；source 撤销后旧 source 数据能够立即退出 active replay。

6. **最新在线候选机制在 Hurdle 上取得 3/3 正迁移。**
   Stage-conditioned target-semantic evidence 在线机制的 Hurdle 结果：
   - 5k–25k AUC paired mean `+24.592`，90% CI `[+7.069,+42.115]`；
   - 30k source-free endpoint paired mean `+119.05`，
     90% CI `[+42.30,+195.81]`；
   - 三个 seed 均为正。

### 0.3 当前尚未解决的核心问题

目前仍然没有得到一个能够独立、可靠地完成自动准入的通用迁移性指标。

最新反例来自 Crawl seed 3：

- 10k 时，run 在 matched student occupancy 上的 25-step target return 与
  target-achievement progress 保守下界都为正，因此被接纳；
- 10k–20k 约 639k 条 run transition 进入 replay；
- 20k 时机制发现 source 不再适合并撤销；
- 但 30k 结果仍相对同 checkout scratch 明显变差：
  - AUC `−156.992`；
  - source-free return `−142.91`；
  - max-dx `−8.07`。

这说明：

> “source 现在能在目标语义下短期做得比 student 好”  
> 不等于  
> “把这些 source 数据写入 replay 后，student 的未来 source-free 学习会变好”。

因此，当前 stage-conditioned target evidence 应定位为：

> **目标语义可行性 / 即时干预证据层**

而不是最终迁移性指标。真正缺少的是第二层：

> **student-relative learning value / delayed handoff utility**，
> 即 source 数据对学生后续 source-free 学习的增量价值。

### 0.4 当前最准确的论文级总判断

本课题已经证明：

- 跨任务 source 干预能够显著改变 humanoid student 的数据分布和学习效率；
- reward-bearing source replay 是有效迁移通道；
- source value 具有 source-specific、task-dependent 和 stage-dependent 特性；
- 有害 source 必须允许严格拒绝；
- 行为权限撤销后，其历史数据也必须同步退出 active replay；
- 但即时 return、动作兼容度、critic 单步 advantage、短期 handoff reward、
  固定 TTL 或目标语义短干预都不足以单独预测长期学习价值。

当前论文主线应继续围绕：

> **How can a humanoid learner identify when a cross-task source improves the
> current student’s future source-free learning, admit it only while beneficial,
> and prevent obsolete source experience from continuing to bias off-policy
> learning?**

## 1. 课题最初设想与两条迁移通道

## 1.1 最原始的 PTF 设想

课题最初想把 PTF 框架直接迁移到 HumanoidBench：

1. 将训练好的 source policies 作为 option；
2. option-value 网络 `Q_ω(s,o)` 阶段性选择当前价值最高的教师；
3. termination 网络 `β(s,o)` 判断何时终止当前教师并切换；
4. 学生在 source 指导下学习；
5. 随训练推进，学生最终脱离 source 独立执行。

原 PTF 的“策略迁移”主要是 policy distillation，不是让 source 直接控制环境：

- 环境动作由 target/student policy 产生；
- 被 option selector 选中的 source 给学生提供动作分布或动作目标；
- 原随机策略版本使用 cross-entropy；
- 当前 FastTD3 actor 是确定性策略，因此项目使用 masked Huber/Smooth-L1 动作对齐
  作为必要适配。

## 1.2 后来发现的 RBO 数据迁移通道

直接移植 PTF 后，option/termination 的自动调度没有形成稳定收益。但实验意外发现：

> 让冻结 source 在 target 环境中执行，并把带 target reward 的 transition 注入
> FastTD3 replay buffer，能够显著加速学生前期学习，部分任务还会提高较长区间表现。

这形成了第二条迁移通道：

### 通道 A：Policy distillation

```text
source(state) → teacher action
student(state) → student action
Huber / masked action matching
→ 更新 student actor
```

### 通道 B：Reward-bearing option/bootstrap replay

```text
source 在 target environment 执行
→ 得到 target reward transition
→ 写入 replay buffer
→ FastTD3 actor/critic off-policy 更新
```

后续证据表明，通道 B 是 SAFE/WFix/RBO 阶段的主要性能来源；通道 A 在
walk→Hurdle 上也有效，但自动 option/termination 调度尚不可靠。

## 2. 端到端系统与当前保留的模块

## 2.1 源策略库

项目已经训练或保存了多个可复用 source，例如：

- `stand`
- `walk`
- `run`
- `reach`
- `hurdle`
- 其他任务专项 source

source 在目标训练期间保持冻结，不通过目标任务梯度更新。

## 2.2 Observation / Action Adapter

由于 source 与 target 任务的 observation 维度和语义可能不同，项目实现了：

- source-specific observation selection/adapter；
- source normalizer 恢复；
- action 维度与 body-group mask；
- `legs_torso`、`arms`、`hands` 等 anatomy group；
- HumanoidBench 目标 observation/action 对齐。

这一层是跨任务调用 source 的必要工程条件，但它本身不是迁移性指标。

## 2.3 Source-target effect / probe

早期 Transfer Map 会把 source 放入 target 环境做短 probe，统计：

- target reward；
- movement/progress；
- fall 或约束；
- 可执行 horizon；
- 静态 `T⁰` 分数与 softmax teacher allocation。

它在 Hurdle 等任务上有排序信息，但跨任务不能稳定预测 learning ROI，特别是在
Crawl 上会把“直立向前走并获得短期 move reward”误认为有益。

## 2.4 Warmup bootstrap

旧 SAFE/WFix 机制：

- warmup 通常为 0–30k；
- 每个 vector env 在 segment 边界选择 source 或 student；
- 选择后锁存并连续执行一个 segment；
- WFix 固定 `h=25`；
- source transition 带 target reward 进入 replay；
- student transition 也进入 replay；
- FastTD3 从混合 replay 更新。

旧机制中的“teacher 0.5 / student 0.5”是外层固定 Bernoulli；如果选到 teacher，
再按 `T⁰` 权重选一个 source，整个 25 步由该 source 执行，并不是在一个 segment
内部让多个 source 各执行若干步。

当前 admission 路径已经改为：

```text
[source_1, source_2, ..., source_n, student]
             ↓
同一个 categorical 分布统一竞争
```

不再存在额外的固定 0.5 teacher floor；无 source 通过时 student 概率严格为 1。
但在单源因果标定实验中，为控制 treatment，仍会人为把单 source 和 student logits
都设为 0，从而得到 0.5/0.5。该设置是实验剂量，不是最终在线机制。

## 2.5 Replay buffer

当前 replay 为每条 transition 记录完整 provenance，主要包括：

- behavior/canonical source；
- 每个 body group 的 source；
- executed group mask；
- segment id / segment step；
- anchor id；
- env rank；
- learner step。

采样层可以表达：

- source/student quota；
- recency；
- TD priority；
- stratum 内 uniform coverage；
- admitted/revoked source mask；
- behavior authority 与 replay eligibility 解耦；
- source 到期或撤销后退出 active replay。

## 2.6 FastTD3 更新

基座保留官方 FastTD3 的关键组成：

- deterministic actor；
- twin distributional critics；
- C51 projection；
- clipped double Q；
- target policy smoothing；
- delayed actor update；
- per-env GPU replay；
- episode-level mixed Gaussian exploration；
- source-free deterministic evaluation。

PTF/RBO 机制只改变：

- rollout 行为来源；
- replay 数据组成和采样；
- 可选 actor distillation loss；
- option/termination 辅助网络。

## 2.7 MCG

MCG 将动作拆为不同 body groups，由 target critic 评估局部动作替换或蒸馏。

它的当前定位是：

- 保留为 source 通过 policy-level admission 后的可选细粒度 authority 层；
- 可限制 source 对目标任务关键部位的干扰；
- 目前没有独立证明其稳定提高性能；
- `bootstrap_only ≈ full` 表明不能将其与 RBO 并列为已证 headline 贡献。

## 2.8 实验指标口径

项目中常用的 `5k–95k nAUC` 或“95k AUC”是：

- 在 5k、10k、…、95k 的 source-free deterministic evaluation return 上做梯形积分；
- 再除以时间区间长度，得到 normalized AUC；
- 因此数值仍与 return 处于相近尺度，表示该训练区间的平均学习表现；
- 它同时反映样本效率和阶段性能，但不能单独说明最终策略上限。

为避免只看 shaped return，项目后来补充：

- source-free endpoint；
- target progress / max displacement；
- task posture / feasibility；
- success/termination 语义审计；
- paired training seeds；
- 固定 evaluation seed panel；
- behavior、main replay、active replay 和 critic sampling 的 source exposure。

当前解释优先级为：

```text
工程 treatment 是否真实发生
→ source-free hard skill / endpoint
→ 配对多种子 AUC
→ 中介量与 shaped return
```

## 3. 科研路线时间线

## 3.1 2026-05：PTF + FastTD3 初始接线

完成：

- official FastTD3 与 HumanoidBench 接线；
- 冻结 source bank；
- observation/action adapter；
- PTF option-value、termination、action distillation；
- source-free student evaluation；
- push 等目标任务的早期诊断。

早期结果：

- Force-PTF / Decay-PTF 在 push 上没有显著差异；
- 发现 beta sigmoid 饱和，并引入 `[0.05,0.95]` 输出限制；
- 当时认为“机制接通但 source-target 可迁移性不足”。

后来的官方代码复审证明，这一早期实现混合了论文、公开代码和项目适配语义，不能把
负结果直接归因成“原 PTF 在 HumanoidBench 必然无效”。

## 3.2 2026-05-30 至 06-08：表征统一路线

依次尝试：

- entity encoder；
- z-native source；
- anchored readout；
- ED-SF / successor-feature 类迁移。

主要结果均为负。核心教训：

> observation 表征统一并不等于 source 技能对 target 可迁移。

问题主要在技能重叠和冻结表征不可适配，而不是简单的 pooling 结构。该路线代码已清理，
结论归档，不再作为现行主线。

## 3.3 2026-06-10 至 06-12：MCG 与 package hard case

MCG/SC-MCG 结果：

- window 任务出现约 `−153` 负迁移；
- significance-calibrated gate 将伤害收窄到约 `−80`；
- 说明 critic-gated transfer 的安全性取决于不确定性，不是简单看 ΔQ 符号。

Package 专项：

- oracle 链与 chain warmup 增加状态覆盖；
- 但成功率仍接近 0；
- 暴露出长程 credit assignment 和 reward event 稀疏问题。

结论：

- MCG 可作受控干预/安全组件；
- package 保留为困难任务案例，不继续用低收益网格抢救。

## 3.4 2026-06-13 至 07-01：RBO、SAFE 与 WFix 主线形成

### RIC / bootstrap 发现

宽 pilot 曾观察到：

- Hurdle ROI 约 `+71%`；
- Cabinet `+53%`；
- Powerlift `+42%`；
- 当时无明显 regret。

但消融显示：

- `bootstrap_only ≈ full`；
- `no_bootstrap ≈ 0` 或为负。

因此主性能来源被重新定位为 reward-bearing warmup bootstrap，而不是 critic gate。

### SAFE / WFix

- SAFE：weighted source + 较长/配置 horizon；
- WFix：weighted source + 统一 `h=25`；
- Random：uniform source allocation 对照。

4 terrain tasks × 3 seeds：

- `WFix − Random = +77.9` 平均 95k AUC；
- 11/12 task-seed cell 为正；
- paired `t=3.08`；
- `SAFE − WFix = −11.4`，`t=−0.46`。

科学含义：

- source allocation 是主要贡献；
- horizon 效果 task-dependent，没有统一主效应；
- “只贪心最新最好轨迹”没有被这些结果支持；
- multi-source 低于 run-only 的局部结果不能直接推出 winner-take-all，应先控制
  source 剂量。

### Hard-progress 审计

为了避免 shaped return 把“站稳”误写成“学会目标任务”，后来补做 source-free hard
metrics：

- Hurdle 50k progress：WFix `0.731` vs scratch `0.356`；
- 100k：`0.922` vs `0.923`。

因此 Hurdle 的收益是真实前期越障加速，而非仅仅站立稳定；但没有稳定提高最终上限。

Cabinet 单源审计中，run-only 的 hard progress 高于 stand-only，说明 source identity
确实影响目标学习，不是所有收益都可解释为通用平衡先验。

### Run-dose 对照

构造 `run24`，使 run 的实际注入份额与 WFix 内 run 份额一致：

- WFix run share `23.894%`；
- run24 与其只差约 `0.065` 个百分点；
- `run24 − WFix` hard progress 仅 `+0.031 ± 0.113`，seed 方向 `−/0/+`。

这不支持“只注入当前 top source 必然优于 mixture”，也不支持 stand/walk 在该实验中
被独立证明为主动有毒。

## 3.5 2026-07-02 至 07-05：老师三点意见与第一轮机制修复

老师三点意见被概括为：

1. 改进 replay sampling；
2. 将 student 作为候选策略；
3. 提出真正的迁移性指标。

### Student-as-arm / online bootstrap

新增 student arm 和在线 reward EMA，但 Crawl：

- student share 约 76%；
- AUC `634.8 ± 77.5`；
- scratch `812.0`。

说明减少 source 执行不等于自动恢复 scratch；历史 source 数据仍可能通过 replay
继续影响更新。

### OBRW

对 replay source exposure 做降权后：

- Crawl `729.5 ± 27.6`，相对 online bootstrap `+94.7`；
- Slide OBRW `614.8 ± 16.0`，高于 online bootstrap `551.3 ± 5.0` 和 WFix
  `522.7 ± 20.0`。

但它仍没有在所有负任务恢复 scratch，不能称为通用安全机制。

### T-gated 与 horizon arms

- 二值 threshold 在弱信号区脆弱，封存；
- multi-horizon arm 增加探索空间后总体失败，封存；
- actor/critic 采样分布不一致会造成 AC mismatch，后续统一由 actor 复用 critic batch。

### 广度结果

代表性 95k AUC：

| Task | Scratch | Random | RBO/WFix | OBRW |
|---|---:|---:|---:|---:|
| Maze | 267.7 | 346.1 | 351.0 | 341.7 |
| Truck | 1156.3 | 1296.6 | 1191.4 | 1304.8 |
| Cabinet | 121.0 | 210.9 | 235.3 | 219.6 |
| Door | 295.0 | — | 285.9 | 295.8 |
| Spoon | 315.4 | — | 346.9 | 354.2 |

加入 Hurdle source 后：

- Truck RBO `1191.4 → 1421.3`，`+229.9`，`t=3.47`；
- Maze 仅 `+0.3`。

这说明 source complementarity 必须与 target headroom 同时存在。

标准任务补充：

- Powerlift `+77.6`，`t=14.78`，3/3 positive；
- Basketball `−101.5`，`t=−2.58`，3/3 negative；
- Balance-hard 近似无差异。

Powerlift 的低 probe 分数仍对应大正迁移，而 Basketball 的弱正 probe 对应强负迁移，
直接否定了 `T⁰` 低分区的方向判别能力。

## 3.6 2026-07-06 至 07-13：核心贡献重构与 Admission Core

### SIV 2×2

构造 matched learner state / replay intervention 的 2×2 分解：

- `B0=-0.0511`
- `R0=-0.0304`
- interaction `I=+0.0331`
- total `T=-0.0484`
- practical threshold `0.10`

结果没有过可测性 gate，复杂 estimator 停止。

### SHU

使用 source→student 与 student→student 的短 handoff 比较：

- direct `+0.0253`
- handoff `+0.1728`
- risk `−0.0156`
- 判 eligible

但下游 SIV total 为负，形成 mandatory contradiction：短期 handoff behavior
有益，不代表 replay/update learning value 有益。闭环 controller 停止。

### Admission Core v1

实现：

- student-inclusive categorical；
- exact abstention；
- quarantine；
- immutable admission snapshot；
- runtime revoke；
- provenance replay；
- source quota / recency / priority / uniform；
- behavior 与 replay 原子更新；
- actor/critic 相同采样分布。

Basketball exact-none 3 seeds：

- source mass / behavior / main replay / critic sampling 全为 0；
- student mass 为 1；
- 与 scratch 的 progress 差约 `+0.031 ± 0.083`，没有负迁移。

这证明 exact abstention 的工程语义成立，但当时的“none”由外部配置给出，尚未自动
发现有害 source。

Powerlift admission-all：

- 30k progress `+0.000388`，`t=4.318`；
- 30k return `+48.57`；

### Compatibility 与 beta 诊断

发现 `sigma=1.5` 使 source compatibility 接近全覆盖；`sigma=0.25` 又导致数据饥饿；
`sigma=0.5` 是覆盖与选择性的候选。但在线 smoke 中 beta 仍贴下界。

均未恢复稳定的状态条件 termination。证据链包括：

- adaptive ξ 的聚合净下压；
- raw beta logits 进入 sigmoid 死区；
- 即使 STE 保留区间外梯度，objective 仍将 logits 推向极端；

### 官方公开 PTF 代码忠实复审

确认公开代码中的关键事实：

- 当 `xi=0` 时使用 `0.8*(top1Q-top2Q)` 自适应 margin；
- 公开 A3C/PPO transfer loss 的活跃行没有乘 `(1−beta)`；
- option Q 本来就是 off-policy 更新，不应误写为 on-policy；
- 论文、公开代码和本项目适配必须分开表述。

实现 `released_code_fidelity` 模式：

- source-only options，无 null；
- reset 立即选 source；
- `Linear → ReLU6` 共享干；
- `Q=tanh`、`beta=sigmoid`；
- beta 先于 Q 更新；
- current transition/current option；
- target Q 每 1000 option updates 硬拷贝；
- tanh transfer schedule；
- 不使用项目 clamp、beta weighting 和 Polyak option target。

单 seed 30k 未缩放 fidelity：

- 5k–25k nAUC `39.53`；
- 25k return `94.97`；
- option/termination 出现非平凡状态条件信号。

但发现 HumanoidBench raw reward 与 `tanh Q∈[-1,1]` 量纲冲突：

- 30k 时约 38%–50% 状态出现所有 option 同时饱和；
- gap 很小；
- 教师排序在不同面板间不稳定。

- 成功消除 Q target 越界和 tanh 饱和；

- 100% 状态 gap<0.01；

> 经典 PTF 在 HumanoidBench + FastTD3 中存在“source-specific signal

## 3.14 2026-07-26：Stage-conditioned target evidence 离线 gate

候选机制：

1. 在当前 student 的真实 occupancy 上冻结 32 个环境状态；
2. 从同一状态分别执行 source 和 student 25 步；
3. 比较 target return 与 target-achievement progress；
4. 使用 5000 次 bootstrap 的 90% LCB；
5. `LCB(ΔR)>0` 且 `LCB(ΔP)>0` 才接纳；
6. 通过者按 progress LCB 排序；
7. 无通过者 exact abstain；
8. probe 数据只进 quarantine。

为避免机制绑定具体任务，核心代码不出现 Hurdle/Crawl 名称。任务通过 YAML
target-evidence contract 描述：

- 什么是 target-achievement progress；
- 哪些约束是目标完成的必要语义；
- 如何从 observation/info/reward components 计算。

离线结果：

- Hurdle@10k：接纳 run、walk，排序 run>walk；
- Crawl@10k：拒绝 stand、walk、run；
- Hurdle@25k：全部弃权，提供 stage-dependent 的描述性证据。

这第一次用相同核心规则同时通过正任务排序与负任务弃权，获准进入低成本在线 gate。

## 8. 已封存或降级的路线

以下路线不应在后续无新证据时重复调参：

1. Entity encoder / z-native / anchored readout / ED-SF；
2. 仅靠 immediate source return 的静态 `T⁰`；
3. 仅靠 critic 单步 action advantage 的绝对符号；
4. T-gated 二值 threshold；
5. 全局 multi-horizon arms；
6. SIV 短程 complex estimator；
7. SHU behavior/handoff score；
8. adaptive reward EMA/UCB revocation；
9. P0 3000-step online counterfactual lease oracle；
10. 固定 30k hard-exit 作为性能提升器；
11. 继续调 sigma/xi/beta_lr 抢救 classic PTF termination；
12. 仅靠 target return + target progress LCB 的单层 admission oracle。

封存不等于工作浪费。它们共同建立了一个非常明确的边界：

> 迁移性不能由 source 当前行为质量直接等价替代，必须落到 source 数据如何改变
> student learner state 与未来 source-free learning。

## 9. 当前支持、尚未支持与必须收窄的主张

## 9.1 已支持

1. Reward-bearing source bootstrap 能在部分 HumanoidBench 任务上显著提高样本效率；
2. Hurdle 上 run/walk source 的 RBO 干预收益跨 3 seeds 稳定；
3. Fixed-walk 动作蒸馏在 Hurdle 上 3/3 提高长区间 AUC；
4. source identity 和 target stage 会改变迁移效果；
5. student-inclusive exact abstention 可严格实现；
6. probe quarantine 可避免探测数据污染；
7. provenance 可追踪 source 数据；
8. source 撤销后 behavior 与 active replay 可同步归零；
9. Hurdle 在线 target evidence 产生 3/3 正迁移；
10. core admission 机制可与 task semantics adapter 解耦。

## 9.2 尚未支持

1. 尚无可靠、一般化的最终迁移性指标；
2. 尚不能保证所有负任务恢复 scratch；
3. 尚不能保证错误 admission 后通过撤销恢复 learner；
4. MCG 尚无独立稳定性能贡献；
5. Classic PTF option/termination 尚未稳定超过 fixed teacher；
6. 尚未证明最终性能上限普遍提高；
7. 尚未在多个任务族完成“正选择 + 负拒绝 + stage handoff”的统一多种子验证。

## 9.3 必须收窄

- WFix 的 `+77.9` 是相对 uniform source allocation 的平均 AUC 增益，不是通用
  transfer ROI；
- Hurdle 的提升主要是样本效率，不应一律写成最终上限提升；
- Exact abstention 的正确性不等于系统已经学会何时 abstain；
- Replay hard-exit 的正确性不等于能够消除已发生的负迁移；
- Q_ω 不是“动作相似度网络”，它学习 option-conditioned return；compatibility
  只改变其训练支持域；
- Q_ω 的 return ranking 也不是 RBO future learning utility；
- Crawl 的 target semantics 适配是 MDP contract，不应被描述成针对 Crawl
  人工特判，但当前合同仍未消除 seed3 learning-value 反例。

## 10. 当前最重要的科学洞见

### 10.1 迁移性是 intervention-specific

同一个 source 通过不同通道介入：

- 动作蒸馏；
- 全动作 target rollout；
- reward-bearing replay；
- body-group MCG；

可能产生不同排序。因此必须先定义“迁移性相对于哪一种干预”。
本论文主标签应以 RBO/replay intervention 为准。

### 10.2 Immediate behavior value 不等于 learning value

已经有多条独立证据：

- Crawl walk/run short reward gain 为正，但 RBO 为负；
- SHU handoff 为正，但下游 SIV 为负；
- adaptive reward 撤销会误撤 Truck 已知好源；
- Crawl seed3 局部 target-semantic evidence 为正，但后续学习变差。

这已经不是偶然噪声，而是本课题的核心科学问题。

### 10.3 Source value 随 student stage 变化

- Hurdle 10k 接纳 run/walk；
- 20k source 集合收缩或切换；
- 25k 离线描述中全部 abstain；
- P0 Truck 10k 后 lease 均值出现负向趋势，而从 0 开始完整 bootstrap 历史为正。

虽然尚无最终 oracle，但阶段依赖性有一致证据。

### 10.4 Replay lifecycle 只能止血，不能回滚

source 撤销后：

- 新 behavior 可停止；
- 旧 transition 可退出 active sampling；

但已经改变的：

- actor/critic parameters；
- optimizer state；
- observation normalizer；
- occupancy；
- 后续学生数据分布

不会自动恢复。Crawl seed3 是最直接证据。

### 10.5 “一般化”不等于“所有任务使用同一个原始坐标”

一般机制应固定：

- matched-state comparison；
- confidence rule；
- admission/abstention；
- quarantine；
- lifecycle。

但不同 target MDP 必须提供：

- 任务完成 progress；
- 必要姿态/接触/约束语义；
- reward component 解释。

这和 Gym 环境提供 reward/termination 一样，是 target contract，不是针对某个 source
或实验结果的硬编码。真正禁止的是把 `crawl`、`run`、历史排名或事后拟合阈值写进
核心 selector。

| 组件 | 状态 | 证据边界 |

| Student-inclusive admission | **完成** | student一等候选、无固定teacher floor |
| Exact abstention | **完成** | 无source时三通道严格0 |
| Quarantine | **完成** | probe数据不进入主replay |
| Reward-bearing bootstrap | **完成并有性能证据** | Hurdle等任务有效 |
| Admission-consistent replay | **完成** | provenance/revoke/handoff/hard-exit |
| MCG/EPS | **保留、后移** | 可选authority，独立性能未证 |
| Classic PTF | **baseline/动机** | distillation有效，自动调度未稳定 |

当前最近的成功不是“最终迁移性指标完成”，而是：

> 已经构造出一个一般化的 target-semantic feasibility 层，并通过 Hurdle 3-seed
> 正迁移验证；同时用 Crawl seed3 找到了该层的决定性反例。

这个反例反而使下一步问题非常清楚：

> 如何判断一批局部行为上看似有益的 source transitions，进入 replay 后究竟会促进
> 还是破坏 student 的后续学习？

## 12. 下一步建议

## 12.1 唯一主问题

下一阶段只应围绕一个问题：

> 构造第二层 student-relative learning-value evidence，使其能保留 Hurdle 的正
> source，同时拒绝 Crawl seed3 的 false admission。

## 12.2 已有可用标定数据

正例：

- Hurdle run / walk 等剂量 3-seed RBO；
- Hurdle online target evidence 3-seed；
- Truck historical positive RBO。

负例：

- Crawl stand/walk/run 等剂量 seed1；
- Crawl online seed3 false admission；
- Basketball historical negative RBO。

对照：

- exact abstention；
- scratch；
- fixed source；
- source-free endpoint；
- source behavior/replay/critic exposure。

下一指标必须同时通过正任务保留与负任务拒绝，不能只在 Hurdle 上调出正确排序。

## 12.3 设计约束

新的第二层不得：

- 退回即时 scalar return；
- 只看裸 root-x；
- 用 student critic 单步 Q 差的绝对符号；
- 事后针对 Crawl 加 source-specific 阈值；
- 用大规模网格寻找一个能过当前结果的常数；
- 在没有可证伪 gate 前直接上 3-seed × 多任务正式矩阵。

它至少应：

- 相对 current student；
- 与真实 replay/update 通道有关；
- 关注 source 数据引起的 learner update；
- 在较低成本下可测；
- 有明确的 abstention 区域；
- 能解释 false-positive 和 false-negative；
- 与 target semantics feasibility 层组合，而不是替代它。

## 12.4 最小推进纪律

遵守“修复—验证—否证—停止”：

1. 先提出一个新的信号族和唯一假设；
2. 先检查是否撞上 T^critic/SIV/SHU/P0 的既有负结果；
3. 用 Hurdle positive 与 Crawl seed3 negative 做最小双向 gate；
4. gate 失败就停止该信号族；
5. gate 通过才进入在线 seed1；
6. 正负任务 seed1 都通过才补 seed2/3；
7. 不再花大量时间证明与核心决策无关的小数精度或底层逐 bit 等价。

## 15. 给后续接手者的一句话

不要把本项目理解成“做了很多 replay 工程但没有迁移指标”，也不要把它理解成“PTF
失败后改做普通 data mixing”。

更准确的理解是：

> 本项目已经证明跨任务 source 数据能在 humanoid off-policy RL 中产生强正迁移，
> 也能产生难以回滚的负迁移；已经完成 student-inclusive abstention、quarantine、
> provenance 和 replay lifecycle；当前真正未解且最有论文价值的问题，是如何把
> “source 当前行为可行”提升为“source 数据对当前 student 的未来学习有益”的可靠
> stage-conditioned transferability。
