## 3. 判据修改：只改前置门，且理由独立于"想让它通过"

### 3.1 改什么

层2 复制检查：`|U_new − U_gate| ≤ 3×paired_se` **且**符号一致
→ **只要求符号一致**（9/9 per-seed 全负）。

### 3.2 为什么这不是"事后放宽"

**理由一（原则性）：复制检查的判据必须与主终点所依赖的量一致。**

```
主终点 = REJECT 决策 = 判定 max_i U_i(K) ≤ 0 = 只依赖**符号**
argmax（谁最不坏）才依赖排序，而它不是本实验的主终点
```

用数值容差去卡一个主终点根本不依赖的量，是**过度约束**——
它拒绝的样本里，有一部分对主终点完全无害。

**理由二（经验性，来自 M27）**：per-seed 数值的 run-to-run 漂移与效应量同量级
（door `|ΔU|` 中位 24.23，效应量 −7~−43），故数值本就不可复现到评估噪声精度；
而符号在 door 上 9/9 复现。

### 3.3 必须披露：我已从看到的数据中推出了什么

用已看到的层2 数值可算出（**本文提交前即已知**）：

```
gate 均值排序：walk(−22.20) > run(−30.63) > stand(−32.64)
v2 批1 排序  ：run(−37.03) > walk(−40.41) > stand(−44.33)
→ 符号：9/9 一致        源间排序：**不一致**（walk / run 换位）
```

**因此本预注册明确放弃"排序复现"作为前置门**——不是因为它会失败，
而是因为 §3.2 的理由一（主终点不依赖排序）。**但我承认我已知道它会失败**，
这一事实必须与判据一并记录，供读者自行折价。

**这也是一个独立发现**：door 的源间差（walk−run = 8.43）与 run-to-run 漂移（±24）
同量级，故其**排序本就不该指望稳健**；对照 hurdle 的 run−walk 间隔 57.14（两批各 3/3）。
