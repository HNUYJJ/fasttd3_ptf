# Stand 可行性探针结果：`STAND_NO_HEADROOM`，并推翻我此前的机制解释

判据冻结于 `stand_feasibility_probe_prereg_20260811.md`（commit 早于运行）。
零训练、纯前向。**不改动 N1 / T4-R / T3 / T2 / Gate A 的任何 verdict。**

## 1. 数据

truck 场景，deterministic zero-shot，16 episodes × 1000 步，panel 与
`p0_evaluator` 前 16 个逐位相同。adapter 自检 **PASS**（四源动作跨时间
标准差 0.34–0.78，绝对值上限 1.000，无恒定输出）。

| 动作来源 | upright | package | return | max_dx | path_len |
|---|---|---|---|---|---|
| `stand` 源 | 0.8404 | 0.2436 | **1061.9** | 0.52 | 3.80 |
| `walk` 源 | 0.5688 | 0.2046 | 694.2 | 0.93 | 4.70 |
| `run` 源 | 0.6107 | 0.1280 | 698.6 | 12.59 | 18.71 |
| `hurdle` 源 | **0.9167** | 0.1655 | **1057.0** | **60.48** | 65.55 |
| *scratch@20k（N1 实测，参照）* | *0.8776* | *0.189* | *1042.6* | *0.29* | *2.39* |
| **N1 注入后三臂（FF/FP/LP）** | **0.7525–0.7771** | 0.189–0.227 | **913.8–944.3** | 0.49–1.64 | 4.2–7.7 |

## 2. 判决

`U_stand = 0.8404`，阈值下界 `0.8776 − 0.03 = 0.8476`。

> **`STAND_NO_HEADROOM`**：`stand` 源在 truck 场景的开环姿态维持能力
> **低于** student 20k 时已达到的水平。"Stand-only 会更会站"这个前提不成立。

## 3. 必须收回的一条：我此前的"移动破坏 upright"是错的

我在 N1 审计中写过"高分策略是站稳少动，而被执行的源 99.996% 是移动类"，
并据此把 truck 负迁移解释为 locomotion 行为与 target 早期最优冲突。

**本探针直接证伪了它**：

- `hurdle` 源跑出 **60.5 米**（完全离开场景），upright 却是四源最高的 **0.9167**，
  比 scratch 的 0.8776 还高 0.039；
- 反倒是 `walk`(0.5688) 与 `run`(0.6107) 的 upright 很低。

所以"移动 ⟹ 破坏直立"不成立。跨栏策略对躯干直立的要求本就比行走严格，
这一点我此前完全没有考虑。**该机制解释作废。**

（此前已收回过一次相关表述：位移与 return 的相关在 16-ep 面板上只有 −0.332
不显著。现在连"位移经 upright 影响 return"这条通路也被否证。）

## 4. 数据真正指向的新事实：混合比任何一个纯策略都差

把三个"纯"策略与"混合"并排看：

| 策略 | 20k return |
|---|---|
| `stand` 源单独执行 | 1061.9 |
| `hurdle` 源单独执行 | 1057.0 |
| scratch student 单独执行 | 1042.6 |
| **50% source + 50% student 混合训练后的 student** | **913.8 – 944.3** |

**三个纯策略的 return 全部落在 1042–1062，而任何混合注入的结果都是 913–944。**
upright 同样：纯策略 0.84–0.92，混合后 0.75–0.78——**低于任何一个成分**。

注意 N1 的评估是 source-free 的，所以 0.75–0.78 是**训练完成后 student 自己**
的水平。因此这不是"混合执行时当场变差"，而是
**"在混合数据上训练出来的 student，最终策略质量更低"**。

这与 T2 的通道分解结论一致（`U^B = −132.8`，behavior 通道有害），
并给它补上了一个此前缺失的对照：**source 的行为质量本身不差，甚至优于 student**。

### 这条解释的证据强度与替代解释

**支持**：四源 zero-shot + scratch + 三条注入臂，共 8 个条件同向。

**未排除的替代解释**（必须列明，本探针无力分辨）：
1. **replay 侧污染**而非 behavior 混合——但 T4-R 已表明纯 replay 修正只回收约一半；
2. **critic 错配**：source 转移的 value 估计与 student 策略不匹配；
3. **provenance 配额**导致的分布偏移（T3 已量化 A≈2.96）；
4. zero-shot 是开环单一策略，与闭环交替执行不可直接等同——
   本探针测的是"源单独跑得如何"，不是"混合当场如何"。

因此第 4 节标题所述只能作为**假设**，不是已确立的机制。

## 5. 一个附带但重要的场地观察

`hurdle` 跑到 60 米外（`package` 项因 margin=4 已基本失效，降到 0.1655），
return 仍有 1057.0，与站在原地的 `stand`(1061.9) 几乎相同。

**说明 truck 在 0→20k 的 reward 几乎只测直立，与"搬箱子"这一任务目标关联极弱。**
这与 `project_all_targets_saturated` 记录的问题同源：
我们反复在 FastTD3 自身已能解决好、且早期信号与任务目标脱钩的区间里寻找迁移收益。

## 6. 边界

1. 零训练开环测量，**不能**预测任何注入实验的训练结果
   （door gate 反例：`run` 的 zero-shot 行为最好却最有害）。
2. `STAND_NO_HEADROOM` 是"Stand-only 缺乏机制依据"，**不是**"Stand-only 必然失败"——
   闭环注入可能产生开环测不到的效应。是否仍要跑，属 PI 裁量。
3. 16 episodes，未做 learner 间检验（zero-shot 无 learner 维度）。
4. 仅 truck、仅 20k 口径、仅该 bank 的四个源。
