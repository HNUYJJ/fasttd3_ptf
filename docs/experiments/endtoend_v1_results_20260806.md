### 2.1 一个稳健的附带效应：端到端把方差压小

```
hurdle   C sd=11.4   vs   A sd=63.1   vs   B sd=331.8
slide    C sd=20.5   vs   A sd=167.3  vs   B sd=16.3
```

`B` 在 hurdle 上 `sd=331.8` 源于 s2 崩到 111.3——即 `hurdle_speedup_v1` 记录的
source 臂独有的 −84% 回撤。**端到端把这个不稳定消除了**（sd 11.4）。
本实验未预注册方差比较，故此项为**描述性**记录。

## 3. 口径 2：总交互对齐（对端到端不利）—— 两个 target 翻转

端到端额外花 **40k** racing 步。按预注册 §4，用 `C@50k`（总交互 90k）
对 `A@100k` 作**保守下界**比较（保守是因为 90k < 100k，端到端还少了 10k）：

| target | C@50k | A@100k | C−A | 胜 |
|---|---|---|---:|---|
| **hurdle** | 703.4 / 739.1 / 659.7 | 349.6 / 352.4 / 460.2 | **+353.8 / +386.7 / +199.4**（mean **+313.3**） | **3/3** |
| **slide** | 490.1 / 590.0 / 540.7 | 912.9 / 601.4 / 862.9 | **−422.8 / −11.4 / −322.1**（mean **−252.1**） | **0/3** |
| **crawl** | 900.5 / 962.2 / 955.4 | 956.3 / 939.6 / 984.9 | −55.8 / +22.7 / −29.4（mean **−20.9**） | 1/3 |

**结论必须并列陈述**：

- **hurdle**：两个口径都稳赢，即使 racing 成本全额计入仍领先 +313。
- **slide**：口径 1 赢 3/3，口径 2 **输 0/3**。原因是 slide 的 scratch 属
  **后期爆发型**（50k=259 → 100k=792），而端到端在 50k 只有 490–590。
  端到端在 slide 上**不是更快，而是最终更高且更稳**（100k：929.1±20.5 vs 792.4±167.3）。
- **crawl**：准入判断正确（避免了 B 的 −151），但代价是 racing 的 40k，
  净额 −20.9。**准入在坏 target 上必然略劣于纯 scratch**——这与预注册 §8 第 5 条
  事先声明的一致，不是意外。

## 4. 三个 target 各自检验了什么（不得混淆）

| target | C vs B 实际检验的是 | 原因 |
|---|---|---|
| hurdle | **退出机制** | 零成本信号与 racing 都选中 `run`，两臂同源，只差退出 |
| slide | **退出机制** | 同上，都选中 `walk` |
| **crawl** | **准入** | 零成本信号选 `run`（位移 14.302 最大），racing 判**全拒** |

**选源**的价值不由本实验检验（由 `hurdle_selection_value_v1` 的 4.95× 支撑）。
这一点在预注册 §3 已事先声明。

## 7. 能与不能声称

**能**：

- 由 racing 自动做出的 9/9 决策与已知真值一致，且组合后的系统在 learner 步数对齐下
  优于 scratch 与盲目用源（各 3/3）；
- 在 hurdle 上，**即使全额计入 racing 成本**仍大幅领先（+313.3，3/3）；
- 端到端显著降低跨 learner 方差（hurdle sd 11.4 vs 331.8）。

**不得**：

1. **不得声称端到端提升样本效率**——口径 2 上 slide 输 0/3、crawl 输 2/3。
   正确表述是"**最终性能更高且更稳**"，仅 hurdle 兼具样本效率优势；
2. **不得只报口径 1**（预注册 §4 明令两个都报）；
3. 不得把 hurdle/slide 上的 `C vs B` 解释为选源价值（§4）；
4. 不得把剂量退出称为贡献（工程基线，PTF 原文 λ 衰减即为此设计）；
5. 不得声称跨任务普适——三个 target 的源标签真值均已知（预注册 §8.5）；
6. **不得省略 slide 上 `C−A` 的裕度不均**：s1 `+15.6`、s3 `+46.0` 相对
   scratch 自身的跨 seed sd（167.3）很小，若换一批 learner 有翻转风险；
7. 不得省略 `M24` 的单批 3 seeds 限制。
