## 3. 独立于判据的描述性事实

以下是观测量，**不是判据的一部分**，也不用于挽救上面的判决：

- **`legs_torso` 的因果影响是 `arms` 的 7.4 倍**（0.4089 / 0.0550）。
  随机化 `legs_torso` 把 return 从 ≈1035 打到 ≈570；随机化 `arms` 只掉到 ≈978。
- `zero_arms`（.045）与 `rand_arms`（.055）量级相近，说明 arms 的影响
  主要来自"偏离已学到的姿态"，而非某个特定动作方向。

### 这对 N1 三个假设各意味着什么

1. **`H_A`（`LP−FP`，保护 arms）**：辨别力**被削弱但未被否定**。
   arms 通路真实存在（5.5%），故 `H_A` 的零效应（−1.9）不能仅归因于
   "测了个无关子空间"。一个仍未被排除的解释是：source 的 arms 动作是
   **另一个训练好的策略**的输出，与随机扰动不同，它未必破坏平衡——
   即"被替换"不等于"被破坏"。本探针无法分辨这两者。
2. **`H_REC`（`LP−S`）的失败在设计上可预期**：LP 保护的是弱通路（arms），
   而把强通路（`legs_torso`，7.4 倍）继续留给 source。这条推论
   **只依赖上面的描述性比值，不依赖已未通过的主判据**。
3. **`H_R`（`FP−FF`）不受本探针影响**：它比较的是 replay 配额，与动作
   子空间无关。

## 4. 边界

1. 全部为 DIAGNOSTIC，不改变 N1 已冻结的 `NDT_NOT_SUPPORTED`。
2. 只测 truck、0→20k checkpoint、16 episodes/条件。
3. 随机扰动是**极端**干预，其效应量不能直接等同于"source 接管该子空间"
   的效应量——这正是 §3 第 1 条所说的局限。
4. `δ` 用相对幅度，未做 learner 间显著性检验（n=10 checkpoint，
   但两臂非独立 learner 总体）。
